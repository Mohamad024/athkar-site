# أذكار الصباح والمساء 🕌

موقع بسيط وأنيق لقراءة أذكار الصباح والمساء، بمصادر صحيحة من الكتب المعتمدة.

## المميزات
- أذكار الصباح والمساء كاملة مع مصادرها (البخاري، مسلم، أبو داود، الترمذي، ابن ماجه...)
- تصميم عربي أنيق بخط ثمانية (Thmanyah)
- تكبير وتصغير الخط
- الوضع الليلي والنهاري
- مسبحة (عدّاد) لكل ذكر

## التشغيل محلياً
افتح ملف `index.html` مباشرة في المتصفح، أو استخدم GitHub Pages.

## رفع على GitHub Pages
بعد دفع الملفات إلى المستودع:
Settings → Pages → Branch: `main` → Save
